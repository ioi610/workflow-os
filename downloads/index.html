开始前，知道这几件事

没有账号步骤，也不用准备 API 密钥。打开后就可以搭建自己的工作流程。

1

各设备分别保存，不会自动同步

内容自动存到当前设备。浏览器版保存在当前浏览器中；请保留应用数据和网站数据。电脑、Android 与浏览器之间不会自动共享工作内容。

2

用“复制全文”搬移框架和文字

复制完整流程后，在另一台设备的“文字生成流程图”中粘贴，可以还原框架和做法文字。旧服务器上的图片不会随文字迁移，需要重新添加。

3

首次安装可能需要系统确认

Windows 若显示来源提示，可核对仓库与 SHA-256 校验后，在提示允许时选择“更多信息 → 仍要运行”。macOS 如阻止打开，可在尝试打开后，到“系统设置 → 隐私与安全性”按提示确认。无需关闭系统防护。

4

网页离线使用，先联网打开一次

安装版已内置页面。网页版和 iPhone / iPad 主屏幕版需要首次联网完整加载；完成缓存后，才能在离线时打开。
